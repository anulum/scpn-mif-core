# SCPNMIFCore.jl

`SCPNMIFCore` contains the Julia reference and acceleration surfaces for the
MIF carrier models, diagnostic processing, sampled safety checks, and AER spike
decoding. The package remains an implementation/prototype surface; simulator and
analytic results do not establish facility-grade hardware evidence.

The [API reference](api.md) is generated from the source docstrings. Its build
fails on missing exported documentation, broken cross-references, and doctest
errors.
