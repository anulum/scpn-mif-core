# Papers

This directory is the authoritative SCPN-MIF-CORE manuscript collection.
Numbered packages under [`submissions/`](submissions/) contain the source,
bibliography, build instructions, citation metadata, verifier, and inspected
review PDF for each distinct paper.

The presence of a package does not imply external submission or publication.
Current status is recorded in each package's machine-readable metadata.
