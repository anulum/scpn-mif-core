# Formally verified deterministic trigger and interlock

This package contains the authoritative JOSS-format manuscript source and its
review PDF. It describes the repository's deterministic trigger/interlock lane
and distinguishes machine-checked RTL properties and local cosimulation from
post-route, hardware-in-the-loop, facility, and plasma-performance evidence.

The manuscript is a review draft and has not been submitted. See
[`BUILD.md`](BUILD.md) for the reproducible local build,
[`submission_metadata.json`](submission_metadata.json) for machine-readable
status, and [`verify_package.py`](verify_package.py) for integrity checks.
